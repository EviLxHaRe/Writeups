# Разведка
Открыв pcap файл видим запросы передачи символов флага и ответ с кодом 200.
```text
4	0.000079	127.0.0.1	127.0.0.1	HTTP	202	GET /flag?symbol=0 HTTP/1.1 
10	0.000797	127.0.0.1	127.0.0.1	HTTP	44	HTTP/1.0 200 OK  (text/plain)
```
Из этого можно сделать, что нам приходит ответ по 1 символу из флага.
Сделаем фильтр, чтобы отображались пакеты с кодом 200 и соберем флаг.
```text
http.response.code == 200 
```
Если выберем покет и перейдем в раздел Hypertext Transfer Protocol, то сможем увидеть содержимое пакета.
```text
HTTP/1.0 200 OK
Server: BaseHTTP/0.6 Python/3.8.0
Date: Mon, 27 Mar 2023 08:27:33 GMT
Content-type: text/plain
C
```
Это 1 символ флага. Если сложим все символы, то получим флаг.
