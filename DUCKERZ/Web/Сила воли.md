# Разведка и решение
Переходим на страницу и видим кликер. Изучив source видим JavaScript код на котором работает логика игры. 
![](../../images/web_strength_1.png)
Чтобы изменить код и купить flag надо 600 000 кликов. Для этого можем изменить значение ``clicks`` и обновить интерфейс. 
```JS
clicks = 600000;
updateUI();
```

Дальше переходим в Shop и покупаем флаг.
