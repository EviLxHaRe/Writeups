# Разведка
```bash
strings reincarnation.img
```
В выводе нашел интересные строки
```text
flag.png.gz
flag.txt.gz
flag.odt.gz
flag.odt
```
И другие подобные файлы. Попробуем с помощью сигнатуры найти сдвиги архивов
```bash
 xxd -g 1 reincarnation.img | grep '1f 8b 08'
```

```text
00121400: 1f 8b 08 08 34 82 50 67 00 03 66 6c 61 67 2e 6f  ....4.Pg..flag.o
00123400: 1f 8b 08 08 85 35 dd 67 00 03 66 6c 61 67 2e 74  .....5.g..flag.t
001f0400: 1f 8b 08 08 86 7f 4c 67 00 03 66 6c 61 67 2e 70  ......Lg..flag.p
001fb000: 1f 8b 08 08 8b 32 dd 67 00 03 66 6c 61 67 2e 74  .....2.g..flag.t
```

Первый сдвиг 00121400, но это шестнадцатеричное число. Надо перевести его в десятичное число. 
```bash
printf '%d\n' 0x121400 # 1184768
```

Узнаем теперь размер архива
```bash
printf '%d\n' $((0x123400 - 0x121400)) # 8192
```

Теперь с помощью утилиты извлекем архив и распакуем его
```bash
dd if=reincarnation.img of=document-region.gz bs=1 skip=1184768 count=8192
gzip -dc document.odt.gz > ferst.txt
```
Вывод
```text
trailing garbage ignored
```

Проделаем тоже самое со вторым архивом. Результат:
```bash
NotDUCKERZ{Is_not_valied_flag} # Фейк флаг
```

Извлекаем последний архив и читаем содержимое
```bash
dd if=reincarnation.img of=last.gz bs=1 skip=2076672
gzip -dc last.gz > encoded.txt
cat encoded.txt
```

Вывод
```text
LJWXQ2C2PE2TAZKIKF2VUM3PIFAUCQKBIFAUCQKBIFAUCQKBIFAUCQKBIFAUCQKBIFAUCQKBIFAU
```

Это base32. Но тут много ступенчатая шифрование флага.
```text
Base32 → Base64 → TAR → gzip → флаг
```
Проделаем эту цепочку дешифрования и получим флаг.
```bash
gbase32 --decode encoded.txt > layer2.txt
base64 -D -i layer2.txt -o layer3.tar
mkdir final-result
tar -xvf layer3.tar -C final-result
gzip -dc final-result/flag.txt.gz > final-result/flag.txt
cat final-result/flag.txt
```
